FuncBind Decoder-First Experiment Plan

Macrocyclic peptide experiments with channel-wise Gaussian splatting.

Core Question

Before modifying latent diffusion, determine whether replacing the FuncBind decoder changes reconstruction quality, atom recovery, or decoding efficiency.

Only Architectural Change

Keep unchanged:
- dataset and splits
- occupancy targets
- encoder
- latent representation
- training protocol

Replace:
INR decoder
    with
channel-wise Gaussian splat decoder

Each atom-type channel—C, N, O, S, F, Cl, P, and Br—predicts and splats its own Gaussian set. Gaussians are density bases, not atom tokens, so multiple Gaussians may represent one atom.

Experiment 1: Decoder Ablation

Train only the reconstruction model:

ground-truth occupancy
    -> existing FuncBind encoder
    -> latent grid
    -> decoder
    -> reconstructed occupancy

Compare:

  • Official FuncBind INR decoder
  • Channel-wise isotropic Gaussian decoder

Measure:

  • channel-wise density reconstruction
  • atom recovery and coordinate RMSD after peak extraction
  • element-type accuracy
  • decoder runtime and memory

Experiment 2: Density Conditioning

After the decoder comparison is stable, test whether experimental density provides additional benefit. 

Baseline:
atomic structure input -> encoder -> decoder

Density-aware:
atomic structure input
+ experimental density input
    -> fused encoder representation
    -> same decoder

BoxBind already provides evidence that density information can help. This experiment tests whether the benefit transfers to FuncBind-style macrocyclic peptide reconstruction.

Decision Gate Before Diffusion

Integrate with latent diffusion only if the new decoder reconstructs the target field reliably and/or density conditioning shows a measurable gain.

    no -> stop or redesign decoder
    yes

Integrate and retrain latent diffusion

Recommended MVP

  • Use the public macrocyclic peptide benchmark.
  • Freeze all design choices except the decoder.
  • Start with K isotropic Gaussians per latent voxel per channel.
  • Use bounded center offsets, positive scales, and sigmoid opacities.
  • Reuse the existing occupancy target and atom-extraction pipeline.
  • Run a single-sample overfit test before dataset-scale training.

Codex Scope

  • Add ChannelWiseGaussianSplatDecoder3D.
  • Keep the existing decoder available as the baseline.
  • Add a differentiable, chunked 3D Gaussian renderer.
  • Add config switches for decoder type, K, scale bounds, and opacity threshold.
  • Add reconstruction, atom-recovery, speed, and memory comparisons.
  • Do not modify or retrain diffusion in the first milestone.
